Jailbreaking computers shouldn't exist

2025+9+7

Every instance of jailbreaking on this post is for computers.
Computers should let the user do whatever they want easily. Anything else is a anti-feature.
There should not be jailbreaking because it means that the computer requires a modification to let the user do whatever they want.
There should also not be "sideloading" because it makes it sound like it is a bad thing or being sneaky.
I suggest the term "installing" and "Fixing a anti-feature"
I think that a computer should let the user do whatever they want without complicated jailbreaks.

Some people think that it reduces security. However it does not reduce security if it has to be enabled. The option to enable it shouldn't have a misleading name like "Enable software that will destroy your computer" or be something that Apple will come up with.
