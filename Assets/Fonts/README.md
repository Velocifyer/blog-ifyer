# Web Font collection
To use a font from here, find the font you want and read the README for it. If there is no README then copy the files from the folder to the server and then follow the instructions in the [The blog post](https://blog.velocifyer.com/Posts/3,0,0,2025-8-13,+how+to+self+host+a+font+from+google+fonts.html) except for step 1 and step 2.
